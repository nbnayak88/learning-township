# Life Skills for Real Life

The Leadership and Identity Transformation capability matrix defines twelve learning pathways. The persona index supplies sixteen learning contexts spanning childhood, youth, adult roles and later life. The public version uses everyday labels for two community cohorts and keeps the age bands and role distinctions. The 64 scenarios are original learning examples.

| Stage | Learner action | Visible outcome |
| --- | --- | --- |
| Find a starting point | Choose a pathway, select a persona, or search by challenge | Matching challenge count and first practice card |
| Notice | Read the scenario | A recognizable situation to reflect on |
| Choose | Answer the pathway question | A value, priority, or response to bring into the decision |
| Try | Practise the specific next action | A small action for the learner's context |
| Review | Check the observable signal | A way to reflect on what happened and decide what to change |
| Compare | Open View all challenges and select a row | Direct jump to a matching challenge |
| Finish | Reach the last match | Next is disabled. Restart returns to the first match |

Start with any situation. If you want a different interpretation or you are supporting a child, use the role and age guidance to choose a better-fitting example. The explorer is a self-guided learning resource and does not assess participants or collect journal responses.

## Authoring approach

Translate ideas about steady effort, moderation, attention, thoughtful speech, humility, patient practice and service into everyday choices. Pair each situation with an action and an observable review point. Keep role names respectful and avoid promising changes in outcomes. For stress-related learning, [WHO's practical stress guide](https://www.who.int/publications/i/item/9789240003927) offers a companion resource.

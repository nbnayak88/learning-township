# Acceleration Checklist

- [ ] Start with the inner work: identity before tactics
- [ ] Go vertical first: finish one program in one sector before spreading
- [ ] Teach what you learn: share notes publicly within 24 hours
- [ ] Use the sector lens: apply one inner core to your own industry
- [ ] Pair up: an accountability partner doubles completion
- [ ] Practise daily in small steps: one reflection, one action, one note

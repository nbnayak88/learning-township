# Qualtrics EX — Survey & Admin Dashboard (Demo)

A standalone interactive employee-experience demonstration with a lime/green interface, five survey journeys, browser-local response collection, and a sample analytics/admin dashboard.

## Launch

GitHub Pages: https://nbnayak88.github.io/learning-township/qualtrics-ex-demo/

## Scenarios

- Engagement Pulse
- New Hire
- Exit Feedback
- Performance Review
- Rewards

## Data and privacy

This is a static demonstration. Sample analytics are synthetic. Submitted answers remain in the visitor's browser storage and are **not** sent to Qualtrics, SAP SuccessFactors, or a server. The admin dashboard is not access-controlled and should not be used with real employee responses.

## Branding

The HTML uses an embedded Qualtrics XM-style vector wordmark to avoid a missing image file. Replace it with an approved logo asset if exact artwork is required.

## Hosting

Publish the repository's `main` branch from the repository root (or use the existing GitHub Pages deployment configuration). The site lives in `qualtrics-ex-demo/index.html`.

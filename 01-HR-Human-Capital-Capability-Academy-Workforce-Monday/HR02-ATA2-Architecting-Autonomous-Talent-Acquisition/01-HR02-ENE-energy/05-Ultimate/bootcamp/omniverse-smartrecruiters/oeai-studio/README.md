# OEAI Studio — AIU-OVE-01

OmniVerse Energy AI Studio · SuccessLabs Academy.

This is a single-agent design prototype for the demand and requisition drafting use case, grounded in the OmniVerse SmartRecruiters delivery pack. It uses original interface recreations with the Joule Studio tour's four-chapter 5/3/4/5 sequence.

Open index.html through an HTTP server. All actions are local simulations; no secrets are needed. The tour separates guided presentation, deterministic drafting, actual local check results and real tenant prerequisites.

Editable components:
- tour.js: chapters and step explanations.
- views.js: original OEAI studio screens.
- engine.js: deterministic guard/draft engine.
- app.js: navigation, preview actions and export.
- style.css: lime/green responsive styling.
- agent-pack/: source prompt, original skill, agent card, proposed contract and local starter.

See WALKTHROUGH.md for source mapping, design-qa.md for verification and agent-pack/README.md for the handoff. The design pack is not an importable SAP package.

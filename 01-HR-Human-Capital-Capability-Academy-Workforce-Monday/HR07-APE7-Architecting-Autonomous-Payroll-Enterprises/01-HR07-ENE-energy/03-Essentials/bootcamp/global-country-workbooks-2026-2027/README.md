# Global Payroll Workbooks — 2026–2027 onward

**SuccessLabs Academy — Architecting Experiences for a Better World.**

62 country workbooks, each available in Excel, Google Sheets, Google Docs, Google Slides, Markdown and Notion. Original interactive HTML editions are included alongside the conversions.

Each edition preserves its original 44 or 48 configuration sections, decision tables, country references, applied experiments and implementation evidence gates. The original statutory review date and pending parameters remain visible. Conversion does not certify a production payroll or automatically update statutory rules.

[Open the country workbook website](https://nbnayak88.github.io/learning-township/)

## Learning tools and editable fields

- **Excel / Google Sheets:** 17 worksheets group the configuration sections by topic. Amber fields support learner progress, answers and notes. The knowledge quiz has formula scoring; the gross-to-net bridge has editable inputs and formulas. Crossword, board game, flashcards, AVG reflection and a notes journal support retrieval and facilitated practice.
- **Google Docs / Markdown / Notion:** complete configuration text and native or Markdown tables, applied experiments, quiz and answer key, 25 flashcards, crossword grid / clues / answers, facilitated board game, AVG prompts, notes journal and calculation guidance.
- **Google Slides:** complete section content, editable decision tables, activities and retrieval material, with sources and answer explanations in presenter notes where appropriate. Tables continue onto additional slides to retain readable text.
- **HTML:** original browser quiz, crossword, Snakes & Ladders, AVG wall, flashcards, sticky notes, progress, table editing, CSV / JSON backup and local autosave.

The editions are independent copies. Edits, notes and completion fields do not automatically sync between formats. Save the Excel or Markdown file after editing; Google and Notion handle their own native saves. HTML browser notes can be exported as a JSON backup.

## Statutory and implementation evidence

Country source facts retain the original workbook evidence-review date. Future-effective provisions, unverified values, source conflicts and employer-specific decisions remain distinct. The arithmetic bridge uses supplied amounts and does not compute a complete statutory payroll.

Fictional employee / employer examples, configuration proposals and suggested tests remain learning material. Tenant configuration, authority submissions, bank settlement and production approval are separate implementation activities. Learner review ticks do not mean a statutory or tenant test passed.

## Format verification

Source-content checks compare every configuration field, table cell, quiz item and flashcard against the generated Markdown, Excel and slide files. Local worksheet / slide previews and presentation package / layout checks support conversion review. Native Google readback checks document tables, spreadsheet tabs, slide counts and editable slide tables. A live Google Sheets experiment verifies the practice formulas and restores the original inputs. These checks concern the learning assets, rather than legal completeness or production payroll execution.

# SuccessLabs Mission Studio

SAP Activate learning expedition: six phases, 82 activity cards, sequential tasks, journals, badges and celebrations.

Live page: https://nbnayak88.github.io/learning-township/mission-studio/

The PDF manual is served alongside index.html. Progress and notes remain in the learner's browser; export before changing browsers or moving from the original site. Import restores a JSON backup.

GitHub Pages hosts the static learning app. Signed certificates are issued and verified by the existing SuccessLabs certificate service; the certificate panel provides the export/import handoff. That service retains its existing sign-in requirements. No signing secrets or learner records are included in this public repository.

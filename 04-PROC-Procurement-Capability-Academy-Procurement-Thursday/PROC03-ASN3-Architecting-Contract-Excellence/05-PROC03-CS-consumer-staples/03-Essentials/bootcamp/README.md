## Learning objective
Implement a contract-authoring, approval and obligation-tracking workflow with clear owners, using automation or AI assistance only where it adds clear value. Applied via Bootcamp mode for Consumer Staples.

## Student output

## Architecture-first learning principle
Teach sector and domain architecture through business outcomes, capabilities, value streams, information, governance, integration, and evidence. Product and vendor technologies are optional implementation examples. Reference applicable TOGAF, BIZBOK, BABOK, DAMA-DMBOK, APQC, GICS and other international frameworks.

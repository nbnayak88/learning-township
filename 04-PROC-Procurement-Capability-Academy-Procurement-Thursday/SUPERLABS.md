## Governance
- Canonical SuperLabs identity and activity methodology are maintained in `nbnayak88/SuperLabs`.
- Academy-specific scenarios and evidence are maintained as context packs.
- Sector/level/format expansion must reference lab IDs rather than fork the labs.
- These are GitHub source links; browser-hosted lab applications require separate deployment validation.

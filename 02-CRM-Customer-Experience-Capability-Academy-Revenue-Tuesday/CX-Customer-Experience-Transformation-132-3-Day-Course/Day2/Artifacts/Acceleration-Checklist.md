# Acceleration Checklist

- [ ] Start with the customer record: fix data before features
- [ ] Go vertical first: finish one academy in one sector before spreading
- [ ] Teach what you learn: share notes publicly within 24 hours
- [ ] Use the sector lens: reuse one design across 11 sectors
- [ ] Pair up: an accountability partner doubles completion
- [ ] Ship small artifacts daily: a journey map, a case, a checklist

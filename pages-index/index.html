How the index stays current

This page automatically reads the current published gh-pages file tree from the GitHub API whenever opened. Newly published HTML pages appear without manually editing the directory. If GitHub's API is unavailable, the last embedded snapshot is shown. The embedded fallback snapshot is refreshed when this index file is republished; the live inventory updates on every page load.

A link listed here means its file exists in the published branch; it does not guarantee an HTTP 200 response. Use the separate live-page audit for availability checks.
